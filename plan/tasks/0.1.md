> **Owner:** HUMAN · **Depends on:** — · **Status:** see the ledger in [`plan.md`](../../plan.md)

## Intent
Every live feature (call, English, voice, logging, hosting) needs a provider account. Keys go into `server/.env` only. An agent cannot create accounts or handle secrets, so this task is human-only and never blocks agent code tasks: all server code is tested with mocks.

## Steps (human)
Follow the reference checklist below. Put values in `server/.env` (copy of `server/.env.example`). Never paste keys into chat, commits, or `web/`.

## Done when
A human confirms `GET /api/health` shows every key `true` on the machine that runs the server (Task 1.C1's manual check). Record "keys present on <machine>" in the ledger's Evidence column.
