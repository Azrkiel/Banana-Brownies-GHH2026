## Intent
Python environment and env-var template for the FastAPI server. It must install on **every** team machine, including the Windows MSI.

## Current repo state (9dced31)
Mostly done. `server/requirements.txt` is a Linux `pip freeze` and pins `uvloop`, which does not build on Windows (`Failed to build uvloop`), so `pip install -r server/requirements.txt` fails on the MSI.

## Steps
1. In `server/requirements.txt`, change the `uvloop==...` line to `uvloop==<same version>; sys_platform != "win32"` (keep the pinned version). Do not change other pins.
2. Run the verify block. Commit: `server requirements: skip uvloop on windows`.
